# REVIBE 🎵

**Don't just listen to music. Feel every moment.**

REVIBE is an open-source music player focused on delivering a modern, customizable, and accessible listening experience.

Developed by Yahee, REVIBE builds upon the InterTune project, recognizing and appreciating the open-source community that made its development possible.

### ✨ Features
- Modern and customizable interface.
- Smooth animations and transitions.
- Personalized appearance settings.
- Accessibility and reduced-motion options.
- Continuous improvements and development.
